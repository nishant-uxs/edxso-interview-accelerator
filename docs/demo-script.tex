\section*{2. Continuous VO (copy-paste teleprompter)}

\begin{quote}
\small
This is Interview Accelerator --- EDXSO Assignment 3. Stack: Next.js App Router, TypeScript, Tailwind, deployed on Vercel. LLM is Gemini via the OpenAI-compatible API.

Input accepts paste or file upload. PDFs go through unpdf on the server, DOCX through Mammoth, then we clip and send JD plus resume to \texttt{/api/analyze}.

Analyze returns structured JSON --- role breakdown, candidate strengths and gaps, claims to probe, and a job-fit score. That is Step~1 and~2 of the product.

Interview is not a fixed question bank. \texttt{/api/interview/next} takes analysis, transcript history, and the last answer, then generates the next question for screening, competency, and deep-dive.

Voice loop is browser-native: \texttt{speechSynthesis} for TTS questions, Web Speech API for STT answers. Optional \texttt{getUserMedia} camera booth --- scoring stays answer-quality first.

Questions are personalised to my resume. The next question reacts to my previous answer across three levels.

After the session, \texttt{/api/interview/evaluate} scores overall plus seven competencies, question-level feedback, prep gaps, and readiness.

You can export a shareable PDF report with jsPDF --- scores, gaps, and per-question feedback.

Architecture is three API routes plus a thin client: analyze, adaptive next-question, evaluate. Live on Vercel, source on GitHub. Full flow: ingest, fit, adaptive voice interview, report. Thanks.
\end{quote}
